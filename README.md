## What's new in 0.85 (August 16, 2026)
- Pageant use-after-free fix
- OpenSSH encrypt-then-MAC buffer
- Private key decrypt buffer
- Two denial-of-service fixes
- Announce list replaced by RSS

## Key Features
- SSH and Telnet
- Serial
- puttygen / Pageant / Plink / PSCP / PSFTP
- 64-bit x86 installer
- Portable zip

## Getting Started
1. Download 0.85.
2. Extract on Windows 10/11.
3. Run `putty.exe`.
4. Host name, SSH, Open.
5. Notes in `files/notes/`.
